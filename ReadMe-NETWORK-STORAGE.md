# DLNA-emu — сетевые хранилища (WebDAV / FTP / FTPS)

Музыка с NAS, облака или FTP-сервера играет на ресивере напрямую: на ресивере появляется
папка **«Сетевые хранилища» → имя хранилища → ваши папки**. Файлы **не копируются** на роутер
и не загружаются в память целиком — трек течёт с хранилища через эмулятор в ресивер.

Новых пакетов ставить не нужно (используются `requests` и стандартный `ftplib`).

## Настройка

Через веб-панель: **Настройки → Сетевые хранилища** (список в YAML, применяется сразу,
без перезапуска) — или в `config.yaml`:

```yaml
network_storages:
  - name: "Мой NAS"                  # имя папки на ресивере, уникальное
    type: webdav
    url: "https://nas.local:5006/music"
    user: "me"
    password: "secret"
    verify_ssl: false                # только если сертификат самоподписанный

  - name: "FTP-сервер"
    type: ftp
    host: "192.168.1.50"
    port: 21
    path: "/music"
    user: "me"
    password: "secret"
```

Адрес можно задать одной строкой: `url: "ftp://me:secret@192.168.1.50:21/music"`
(`type` определится по схеме: `http(s)`/`dav(s)` → WebDAV, `ftp`/`ftps` → FTP).
Без `user` FTP подключается анонимно.

### Параметры

| Параметр | Для чего | По умолчанию |
|---|---|---|
| `name` | имя на ресивере (от него зависит внутренний id — после переименования плейлисты ресивера «потеряются») | host |
| `type` | `webdav` · `ftp` · `ftps` (FTP поверх TLS, команда `AUTH TLS`) | по `url` |
| `url` | WebDAV: адрес папки с музыкой. FTP: можно вместо `host/port/path` | — |
| `host`, `port`, `path` | FTP: сервер, порт (задать вручную; по умолчанию 21, не дописывается в host), стартовая папка | `—`, `21`, `/` |
| `user`, `password` | логин и пароль | пусто |
| `verify_ssl` | проверять сертификат (WebDAV по https, FTPS) | `true` |
| `auth` | WebDAV: `basic` или `digest` | `basic` |
| `passive` | FTP: пассивный режим (почти всегда нужен) | `true` |
| `encoding` | FTP: кодировка имён. Если не задана верно — определяется автоматически (UTF-8 → cp1251) | `utf-8` |
| `honor_range` | `false` — всегда отдавать файл целиком, игнорируя перемотку (как USB для Yamaha RX-V777 и похожих; включайте, если ресивер зависает/пропускает треки) | `true` |
| `cache_sec` | сколько секунд помнить содержимое папки | `60` |
| `timeout` | таймаут соединения, сек | `20` |
| `enabled` | `false` — временно отключить, не удаляя | `true` |

## Что показывается

Папки и аудиофайлы (`mp3 flac m4a aac ogg opus wav wma aiff ape wv mpc`). Остальное
(картинки, текст), скрытые файлы и служебные папки NAS (`@eaDir`, `#recycle`,
`$RECYCLE.BIN` …) скрыты. Сортировка «человеческая»: `2 - …` идёт раньше `10 - …`.
Отдаются по HTTP тоже только аудиофайлы внутри заданной папки хранилища.

Если хранилище недоступно (неверный пароль, нет сети, сертификат), внутри его папки на
ресивере будет строка с причиной — `⚠ WebDAV: 401 — неверный логин/пароль …`.
Подробности — в логе (веб-панель → Логи).

## Перемотка

Ресиверы, которые не просят `Range`, получают файл целиком (как с USB). Те, что просят,
получают нужный кусок: WebDAV пробрасывает `Range`, FTP использует `REST`.
Для USB-файлов в эмуляторе перемотка отключена ради Yamaha; для сетевых хранилищ она
включена. Если ваш ресивер с ней капризничает — `honor_range: false` в записи хранилища.
Если сервер этого не умеет, эмулятор сам пропускает нужное число байт (медленнее на
больших смещениях).

## Частые проблемы

- **WebDAV `401`** — неверный логин/пароль; у некоторых серверов нужен `auth: digest`.
- **Ошибка SSL-сертификата** — добавьте `verify_ssl: false` (самоподписанный сертификат).
- **WebDAV на Synology / QNAP / Nextcloud** — `url` это адрес *папки* WebDAV, например
  Nextcloud: `https://host/remote.php/dav/files/ЛОГИН/Music`.
- **FTP: пустой список / «нет связи»** — проверьте порт и `passive: true`; пассивные
  порты сервера должны быть доступны роутеру/ПК с эмулятором.
- **FTP: вместо русских имён «кракозябры»** — задайте `encoding: cp1251`.
- **FTPS** — поддерживается явный FTPS (порт 21 + `AUTH TLS`). Неявный FTPS на порту 990
  не поддерживается.
- **SMB/NFS (общие папки Windows)** — не поддерживаются напрямую; смонтируйте их в ОС
  и укажите путь в `files → roots`.

## Ограничения

- Обложки для файлов из сетевых хранилищ не отдаются (для USB отдаются).
- `.m3u` плейлисты внутри хранилищ не разбираются — в списке видны сами файлы.
- Пароли хранятся в `config.yaml` открытым текстом (как и токены сервисов).
