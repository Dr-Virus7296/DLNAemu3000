Я написал эмулятор который умеет подсовывать вашим ресиверам, плеерам и другим устройствам - потоки с стриминг сервисов:

    Deezer
    Яндекс музыка
    Zvuk
    Kion music
    Drivemusic
    Zaycev net
    аудиокниги (akniga)
    PromoDj
    Монтировать сетевые каталоги по FTP и Web-Dav
    Слушать онлайн радио
    Слушать музыку и плейлисты с USB накопителя

Поддержка FLAC напрямую (если ваше устройство вообще поддерживает FLAC), поддерживается поиск музыки в стримингах (через веб морду), в deezer и яндекс музыке поддерживает мою волну, поддерживается текущий плейлист (показывает на каком треке вы остановились в предыдущем плейлисте), поддерживает мультиаккаунты (если у вас семья и у каждого свой аккаунт условно в яндекс музыке, достаточно тыкнуть в какой аккаунт будете входить). Авторизация работает через токены/arl.

Кто-то спросит “а зачем, есть же LMS” - есть, но установка его куда более сложная и нельзя установить на роутер, плюс более прожорлив в плане ресурсов!
Все это работает на устройствах где можно установить питон (относительно не старые роутеры keenetic с entware), windows и linux.

Если нужно ffmpeg.exe для windows (положить папку в корень эмуля) - https://drive.google.com/file/d/1AGZyXKzCYcavLQ6vz1OlhMD74Gz9zM3w
