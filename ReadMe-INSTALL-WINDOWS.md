# DLNA-emu — установка на Windows (ПК / ноутбук / мини-ПК)

---

## 1. Установи Python 3.12

Скачай установщик:

https://www.python.org/downloads/release/python-3129/

Файл: **Windows installer (64-bit)** — `python-3.12.9-amd64.exe`

### Важно при установке

На первом экране поставь галку внизу:

- [x] **Add python.exe to PATH**

Без неё команда `python` в cmd работать не будет.  
Жми **Install Now**, дождись конца.  
Открой **новое** окно командной строки (старое PATH не подхватит).

### Проверка

```bat
python --version
pip --version
```

Ожидается: Python 3.12.x и pip 24.x / 25.x.

---

## 2. Распакуй архив

Например в `C:\dlna-emu`.

Должно получиться:

```text
C:\dlna-emu\
├── dlna_emu\              ← папка с .py (пакет)
│   ├── __main__.py
│   ├── server.py
│   ├── webui.py
│   ├── providers\         ← площадки (deezer, zvuk, yandex, …)
│   └── …
├── radio\                 ← твои .m3u (создай папку)
├── config.yaml
├── requirements.txt
└── akniga_favorites.json  ← появится после «⭐ В избранное»
```

> Если в архиве только папка `dlna_emu` с модулями — положи её внутрь `C:\dlna-emu\`, чтобы путь был `C:\dlna-emu\dlna_emu\__main__.py`.

---

## 3. Командная строка

```bat
cd /D C:\dlna-emu
```

Должно стать: `C:\dlna-emu>`

---

## 4. Зависимости

```bat
pip install -r requirements.txt
```

Если несколько Python и pip ругается:

```bat
python -m pip install -r requirements.txt
```

| Пакет | Зачем |
|--------|--------|
| `requests` | сеть (Deezer, Яндекс, Звук, PromoDJ, …) |
| `PyYAML` | конфиг |
| `pycryptodome` | расшифровка Deezer / akniga |
| `Pillow` | (опционально) обложки для ресиверов |

**ffmpeg** (для akniga.org — главы книг):

1. Уже есть в архиве в папке ffmpeg-for-windows
2. Укажи путь, например D:/dlna-emu-3000/ffmpeg-for-windows/ffmpeg.exe 

---

## 5. Конфиг `config.yaml`

Создай рядом с папкой `dlna_emu` (в `C:\dlna-emu\config.yaml`).

**Минимум:**

```yaml
server:
  name: "DLNA-emu"
  announce_ip: "192.168.1.50"   # LAN-IP этого ПК
  port: 8200

web:
  enabled: true
  port: 8088

radio:
  folder: "C:/dlna-emu/radio/"

deezer:
  arl: ""

yandex:
  token: ""

akniga:
  enabled: true
  ffmpeg: "C:/dlna-emu/ffmpeg/bin/ffmpeg.exe"
  chapter_kbps: 128

drivemusic:
  enabled: true

files:
  roots: []
```

### Пути в YAML на Windows

Пиши **прямые** слэши и в **кавычках**:

| Правильно | Неправильно |
|-----------|-------------|
| `"C:/dlna-emu/radio/"` | `"C:\dlna-emu\radio"` |

### Как узнать LAN-IP

```bat
ipconfig
```

Строка **IPv4-адрес** у активного адаптера (Ethernet / Wi-Fi).  
**Не** бери `127.0.0.1`.

### ARL Deezer

1. Открой [deezer.com](https://www.deezer.com) → **F12**  
2. **Application** (или Storage) → **Cookies** → `https://www.deezer.com`  
3. Cookie **`arl`** → скопируй значение → вставь в `deezer.arl`

### Токен Яндекс.Музыки

В веб-панели DLNA-emu → **Настройки** есть ссылка на OAuth, или вставь готовый token в `yandex.token`.

---

## 6. Радио

Положи `.m3u` в `C:\dlna-emu\radio\` (создай папку, если нет).

---

## 7. Запуск

Через файл start-windows.bat

### Брандмауэр Windows

При **первом** запуске появится окно «Разрешить доступ…» — разреши для **частных сетей**.  
Без этого ресивер сервер не увидит.

---

## 8. Веб-панель

**http://192.168.1.50:8088**  
(подставь свой IP)

| Раздел | Назначение |
|--------|------------|
| **Статус** | сервер, радио, Deezer, akniga, избранное |
| **Настройки** | порты, ARL, токен, radio, USB |
| **Радио** | список m3u, «Перечитать» |
| **🔍 Поиск** | Deezer / DriveMusic / Яндекс / **akniga.org** (страницы поиска) |
| **⭐ Избранное** | до **500** книг; файл `akniga_favorites.json` рядом с конфигом |
| **Консоль** | живой лог; кнопка «Скачать лог» |

На поиске akniga:

- **+ В DLNA** → на ресивере **🔍 Мои книги** (до перезапуска)  
- **⭐ В избранное** → **⭐ Избранное** (сохраняется на диск)

---

## 9. Ресивер (Yamaha, Onkyo, Denon, Pioneer…)

**Сеть → Server / DLNA → обновить список**

Найди **DLNA-emu** (или `server.name`):

- **Radio** — m3u  
- **Deezer** / **DriveMusic** / **Яндекс.Музыка**  
- **akniga.org (аудиокниги)** — Мои книги / Избранное / Жанры  
- **Файлы (USB)** — если задан `files.roots`

---

## 10. Остановка

В окне сервера: **Ctrl+C**.

# Автозапуск BAT-файла в Windows

Настроить автозапуск `.bat` файла можно несколькими способами. Выбор зависит от того, нужны ли вам особые права, должна ли программа работать скрытно или запускаться для всех пользователей сразу.

## 📁 Способ 1: Папка «Автозагрузка» (самый простой)

Идеален для обычных пользовательских скриптов, запускаемых после входа в систему.

1. **Создайте ярлык**: Щёлкните правой кнопкой мыши по вашему `.bat` файлу → **«Создать ярлык»**.
2. **Откройте папку автозагрузки**: Нажмите `Win + R`, введите `shell:startup` и нажмите Enter.  
   Откроется папка `C:\Users\Имя_Пользователя\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`.
3. **Переместите ярлык** в эту папку. Скрипт будет запускаться при каждом входе в систему для текущего пользователя.

> **Важно**: Если скрипту нужны права администратора, щёлкните по ярлыку правой кнопкой → **«Свойства»** → **«Дополнительно»** → установите галочку **«Запуск от имени администратора»**.

## 🗓️ Способ 2: Планировщик задач (гибкий и мощный)

Даёт больше контроля: запуск до входа пользователя, скрытие окна консоли, особые условия.

1. **Откройте Планировщик**: `Win + R` → `taskschd.msc` → Enter.
2. **Создайте задачу**: В правой панели выберите **«Создать задачу»** (не «Создать простую задачу»).
3. **Вкладка «Общие»**:
   - Дайте задаче понятное имя.
   - Для скрытного фонового выполнения выберите **«Выполнять независимо от того, вошёл ли пользователь в систему»** и установите галочку **«Скрыть»**.
   - При необходимости отметьте **«Выполнять с наивысшими правами»**.
4. **Вкладка «Триггеры»**: Нажмите **«Создать»** → выберите **«При входе в систему»** или **«При запуске»**.
5. **Вкладка «Действия»**: Нажмите **«Создать»**, в поле «Программа или сценарий» укажите полный путь к вашему `.bat` файлу.
6. Сохраните задачу, нажав **«ОК»**.

## ⚙️ Способ 3: Групповая политика (для всех пользователей)

Подходит для настройки на компьютерах в домене или для всех учётных записей. Требует прав администратора. Скрипт выполняется **до входа пользователя в систему**.

1. `Win + R` → `gpedit.msc` → Enter.
2. Перейдите по пути: **Конфигурация компьютера** → **Конфигурация Windows** → **Сценарии (запуск/завершение)**.
3. В правой панели дважды щёлкните по пункту **«Автозагрузка»**.
4. Нажмите **«Добавить»** и укажите путь к вашему `.bat` файлу.

> **Примечание**: Редактор групповых политик (`gpedit.msc`) доступен не во всех редакциях Windows (например, в Домашней версии его может не быть).

## 🗃️ Способ 4: Редактор реестра (продвинутый)

Изменяет системный реестр. Будьте осторожны: неверные изменения могут повредить систему.

1. `Win + R` → `regedit` → Enter.
2. Перейдите в один из разделов:
   - **Только для текущего пользователя**: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
   - **Для всех пользователей (нужны права администратора)**: `HKEY_LOCAL_MACHINE\Software\Microsoft\Windows\CurrentVersion\Run`
3. Щёлкните правой кнопкой мыши по разделу `Run` → **«Создать»** → **«Строковый параметр»**.
4. Задайте параметру любое имя, а в поле **«Значение»** укажите полный путь к вашему `.bat` файлу в кавычках, например: `"C:\Scripts\my_script.bat"`.

## 💡 Как сделать запуск скрытным (без чёрного окна)

При использовании Планировщика задач или папки «Автозагрузка» может на мгновение появляться окно командной строки. Чтобы избежать этого, создайте VBS-скрипт-обёртку:

1. Создайте новый текстовый файл и вставьте следующий код:
   ```vbscript
   Set WshShell = CreateObject("WScript.Shell")
   WshShell.Run Chr(34) & "C:\Путь\К\Вашему\Файлу.bat" & Chr(34), 0
   Set WshShell = Nothing
   ```
2. Замените `C:\Путь\К\Вашему\Файлу.bat` на реальный путь к вашему скрипту.
3. Сохраните файл с расширением `.vbs` (например, `launcher.vbs`).
4. Настройте автозапуск (любым из способов выше) для этого `.vbs` файла, а не для самого `.bat`.

## Частые проблемы

| Симптом | Решение |
|---------|---------|
| `python` не является командой | При установке не поставили **Add to PATH** → переустанови Python с галкой; или `py -3.12 -m dlna_emu -c config.yaml` |
| Ресивер не видит сервер | `announce_ip` = LAN-IP; одна подсеть; брандмауэр → разрешить Python для **частных** сетей; UDP **1900** / TCP **8200** |
| Веб не открывается | `web.port` (8088); разрешить TCP 8088 в брандмауэре |
| Deezer пустой / не играет | ARL протух или пустой; `pip install pycryptodome`; в логе должно быть `Deezer login OK` |
| DriveMusic пустой | в логе «используем https://…»; если «ни одно зеркало» — сайт режет IP |
| akniga без звука | путь к `ffmpeg.exe` в `akniga.ffmpeg` |
| Избранное пропало | должен быть файл `C:\dlna-emu\akniga_favorites.json` |
| Не играет FLAC на старом ресивере | в качестве Deezer ставь `mp3_320` / `mp3_128` вместо FLAC |
